# CloudZero Python template

Skeleton Python package used by the CloudZero open source template.

- Requires Python 3.11 or newer
- Uses [uv](https://docs.astral.sh/uv/) for installs and locking
- Uses Ruff for format and lint, pytest for tests

See the repository [README](../README.md) and [CONTRIBUTING](../CONTRIBUTING.md)
for setup and contribution steps.
